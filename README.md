# WeKnora-Lite_0.8.3_windows_amd64_portable
Tencent has open-sourced WeKnora, but it lacks a ready-to-use desktop application. Therefore, this project compiles the WeKnora source code to produce a portable, ready-to-use WeKnora desktop application. The software can be downloaded from the release page. 

腾讯开源了WeKnora，但是缺少直接可用的桌面应用。基于此，本项目对WeKnora项目进行编译，产生便携可用的WeKnora桌面应用。软件可以在release中下载。
